리디 결제 장부

저장한 결제내역 html을 올리면 총 금액과 카테고리별 금액을 확인할 수 있습니다.
❔ 사용법 / 도움말 펼치기

1. 데이터 넣는 방법

이 페이지는 HTML 파일 업로드만 지원합니다. 리디 마이리디 → 결제 내역 페이지를 브라우저에서 Ctrl+S(다른 이름으로 저장)한 뒤 올려주세요. 결제내역은 페이지가 나뉘어 있어서 (1, 2, 3페이지…) 전체를 보려면 각 페이지를 따로 저장해서 한 번에 여러 개 올리면 됩니다. 이때 페이지를 하나하나 저장하는 것이기 때문에 매우 귀찮으실 수 있습니다. 만약 Claude AI를 구독중이시라면 2번째 방법을 추천드립니다.

2. Claude in Chrome을 사용할 때 (프롬프트 복사해서 사용하세요)

이 방법은 Claude AI Pro 이상을 구독하고 계신 분들께 추천드립니다. 무료 버전은 Claude in Chrome을 사용할 수 없습니다.

리디북스 ridibooks.com/order/history 페이지 결제내역을 긁어줘.
1페이지부터 마지막 페이지까지 순서대로 이동하면서 각 행의 날짜, 제목, 금액, 결제수단을 수집해줘.
가공(필터링, 합산)은 하지 말고 원본 그대로 사용할 거야.

수집한 데이터를 아래와 똑같은 <table> 구조를 가진 HTML 파일로 만들어서 저장해줘.
행 순서는 각 td에 날짜, 제목, 금액, 결제수단 순서로 넣어줘 (금액은 "1,000원"처럼 숫자+원 형태 그대로 둬도 돼).

<!DOCTYPE html>
<html><body>
<table class="buy_history_table">
  <tbody>
    <tr><td>2026.07.14. 18:10</td><td>하나의 더치 80화</td><td>100원</td><td>리디포인트</td></tr>
    <!-- 수집한 행마다 위와 같은 형식으로 tr을 추가 -->
  </tbody>
</table>
</body></html>

완성되면 파일로 저장해서 다운로드해줘 (예: my-ridi-order.html).

필터링(0원 제외, "기다리면 무료" 제외)과 회차 합산은 이 페이지가 알아서 처리해줍니다. Chrome에는 원본만 그대로, 위 표 형식 그대로 담아달라고 하는 걸 추천해요. 완성된 HTML 파일을 다운로드한 뒤 위 업로드 칸에 그대로 올리면 바로 인식됩니다.

3. 자동으로 처리되는 것들

  • 결제수단이 "기다리면 무료"인 항목, 금액 0원인 항목 → 자동 제외 (건수는 표시)
  • 제목이 "OO화"로 끝나는 항목 → 같은 작품끼리 자동으로 묶어서 금액 합산
  • 카테고리(단행본/웹툰/웹소설/기타)는 "화" 패턴으로 1차 추정 후, 항목별 드롭다운으로 직접 수정 가능

4. 데이터는 어디에 저장되나요

업로드한 파일은 서버로 전송되지 않고 사용자의 브라우저 안에서만 처리됩니다. 카테고리 수정 내역만 이 브라우저의 로컬 저장소에 남고 새로고침하면 초기화됩니다. 단, 업로드한 원본 파일 자체는 저장되지 않으니 다시 열면 파일을 다시 올려야 해요.
